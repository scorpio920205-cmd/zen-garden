# 精進花園 (Zen Practice Garden)
### 高級禪修班學員 專修 2D 虛擬修持花園暨雲端打卡系統

> **「人在哪裡，心就在哪裡。一念清淨，即是自性花開。」** —— 惟覺安公老和尚《中台月刊》法語開示

本專案專為精舍**日間高級禪修班（日高）**與**夜間高級禪修班（夜高）**學員量身打造。將學員每日的靜坐與誦經定課，化為甘露法水注入蓮池，在 2D 精進花園中動態培育盛開生機盎然的**蓮花**與向陽**太陽花**。

---

## 🌟 核心規範與設計特色

1. **登入 / 建檔入口門檻 (Gatekeeper)**：
   - 進入網站首先呈現「修持登入」卡片，未登入前不會顯示花園與打卡面板。
   - **首次登入（建檔）**：
     - 若**無學號**：僅需填寫**班級**（日高/夜高）、**組別**（A1~B4）、**真實姓名**（三項必填即可登入）。
     - **法名**：選填（非必要填寫；若有填寫會在他人花園公開顯示）。
     - **學號**：選填。
   - **二次登入（快速登入）**：
     - 若初次有填寫學號，日後可**僅憑學號一鍵快速登入**！
     - 若無學號，輸入「班級＋組別＋姓名」三項亦可立即登入進入個人花園。

2. **草皮與澄澈蓮池 · 蓮花盛於池塘 ＋ 太陽花生於草皮（無泥土）**：
   - **純淨草皮池塘底圖**：畫布無泥土污濁，左下角為澄澈水池，中央為綠茵草坪。
   - **打卡動態三階段生長（依打卡次數計）**：
     - 每打卡 3 天增添一朵新花。
     - **第 1 天｜初萌種子**：池中碧綠荷葉展露清晨小荷芽；草皮上萌發向陽嫩葉。
     - **第 2 天｜含苞待放**：水面立起粉紅荷苞；草皮挺拔向日葵翠綠花蕾。
     - **第 3 天｜花朵綻放**：池中一朵蓮花盛開；草皮向陽花朵朵金黃盛開！
     - **例**：打卡 10 天 = 3 朵盛開花朵 ＋ 1 朵初萌種子；打卡 11 天 = 3 朵盛開花朵 ＋ 1 朵含苞待放；打卡 12 天 = 4 朵盛開花朵。
   - **五階段林木漸茂與草堂演進背景**：
     - 5 張畫風一致的高解析底圖，池塘固定於同一位置，隨著階段草堂漸成大舍、林木漸深成林：
       - 第 1 階段：`stage_1_seed.jpg`（初植善念 · 澄澈靈泉）
       - 第 2 階段：`stage_2_sprout.jpg`（法水滋潤 · 萌發新綠）
       - 第 3 階段：`stage_3_bloom.jpg`（菩提成蔭 · 繁林草舍）
       - 第 4 階段：`stage_4_autumn.jpg`（秋收功德 · 萬木成林）
       - 第 5 階段：`stage_5_winter.jpg`（冬藏圓滿 · 大道堂舍）
   - 打卡時伴隨**甘露水注入動畫**與**空靈水聲/音缽音效**。

3. **保留木牌老和尚法語**：
   - 花園中木牌對齊《中台月刊》惟覺老和尚開示法語（每日固定一則隨機法語，澄心領受，安住當下）。
   - 標籤精簡不遮擋花園，點擊即可彈出專屬對話窗恭讀領受。

4. **精簡修持打卡項目（自選勾選：可只誦經或只有靜坐）**：
   - **靜坐調心**：可勾選/取消，展開填寫靜坐分鐘數。
   - **每日誦經**：可勾選/取消，可選金剛經、藥師經、普門品或自訂經典名稱。
   - **自由定課組合**：可只每日誦經、只靜坐調心，亦可兩者皆選。無卷數、無持咒。
   - **支援歷史補打卡**：勾選「補打卡之前時間」，可自選過往日期時間補登。

5. **版面純淨沉穩**：
   - 移除多餘冗贅按鈕，專注於花園與每日用功。

6. **參觀他人花園（蓮池海會）＆ 嚴格安全隱私保護**：
   - 學員可點擊「🌸 參觀學員花園」，在右側抽屜中瀏覽日高、夜高同修名錄。
   - **隱私安全性**：進入他人花園時**「只能看到班級與法名」**，學號與真實姓名被**嚴格過濾遮蔽**，杜絕個人隱私洩漏。
   - 進入同修花園可欣賞其打卡累積盛開的蓮花與太陽花，並可點擊「🙏 隨喜讚嘆合掌」。

7. **最高權限師父管理後台 (`admin.html`)**：
   - **獨立入口與權限隔離**：學員介面完全無管理後台連結或返回按鈕，雙邊嚴格分離。
   - **密碼防護與安全保持**：採用專屬管理金鑰防護，未經授權無法閱覽。
   - **完整審閱與巡檢功能**：
     - 指導法師可查閱全班未脫敏名錄（真實姓名、學號、組別、打卡次數、禪坐總分鐘數）。
     - 支援進入個別學員 2D 花園巡視，完成後點擊頂部專屬「返回管理名錄」，絕不會錯轉為學員身分。
     - 法師可直接在學員打卡紀錄下方批註提點開示。
     - 具備學員資料與打卡紀錄之最高權限維護管理功能。

8. **般若智慧卡 · 菩提收集冊（法語抽卡）**：
   - **花朵換法語**：花園中每開出一朵花（修持打卡），即可獲得 1 次抽卡機會。
   - **迎新法緣禮**：初次登入免費贈送 5 張開冊抽卡禮。
   - **70 張法語全收錄**：涵蓋《中台月刊》老和尚法語、《金剛經》、《藥師經》、《普門品》。
   - **純淨無干擾**：無社群分享與迴向按鈕，專注法語內省。

## 🔒 資訊安全與隱私保護原則

1. **真實個資絕對隱蔽**：
   - 本平台僅供精舍禪修班學員內部修持互勉之用。
   - 學員間互動參觀時，系統在前端與後端資料庫查詢（SQL）雙層嚴格過濾，**學號與真實姓名永遠不對其他學員公開**。
2. **管理金鑰安全規範**：
   - 後台管理密碼由精舍指導法師專屬保管，切勿以明文形式散布於公開網路。
   - 雲端環境中請統一採用**加密環境變數（Encrypted Secrets）**儲存，杜絕洩漏風險。
