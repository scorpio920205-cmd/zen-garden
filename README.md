# 精進花園 (Zen Practice Garden 2026)
### 中台禪寺精舍學員專屬 ｜ 2D 開心花園 ＆ 雲端打卡共修名錄系統

> **「靜則一念不生，動則萬善圓滿。人在哪裡，心就在哪裡。」** —— 惟覺安公老和尚《中台月刊》開示

本專案專為精舍**日間高級禪修班（日高）**與**夜間高級禪修班（夜高）**學員量身打造。將學員每日的靜坐、誦經、持咒、念佛拜佛、出坡與聞法反省，轉化為 2D 開心花園中生生不息的「自性福田與芬芳花朵」。同時提供同修「蓮池海會」相互參觀、除妄念蟲、澆灌甘露法水與合掌隨喜功能，並具備嚴格的個資隱私防護與最高權限管理員後台。

---

## 🌟 核心功能特色

1. **獨立 2D 開心花園 (`garden2d.html`)**：
   - 經典開心花園 2.5D 俯視視角：綠草如茵、白木籬笆、洋傘休閒桌椅、清淨水池與鵝卵石小徑。
   - **多塊圓形修持土堆福田**（智慧蓮花、忍辱紫菊、清淨白菊、慈悲茉莉、菩提幼苗、開墾福田）。
   - **經典遊戲化道具列**：
     - 👆 **查看**：檢視花圃修持進度、水分與老和尚開示。
     - 🎒 **播種**：挑選要栽種的佛法定課（金剛經、心經、大悲咒、坐禪等）。
     - 🧴 **除妄念**：點擊花圃上的可愛「雜念蟲」，觀照自心，雜念化為菩提彩蝶！
     - 🚰 **澆甘露**：為花圃澆灌甘露法水，伴隨清脆水滴音效與功德點數。
     - 💰 **迴向**：花朵盛開後點擊「普皆迴向十方法界」。
     - ⛏️ **開墾**：開闢新修持福田。
   - **右側「同修好友 (Friends)」抽屜**：隨時點擊右側邊緣標籤展開同修清單，無縫進入同修花園逛，幫同修澆甘露水、除妄念或合掌隨喜！
   - 同時保留 [`garden3d.html`](file:///E:/%E7%B2%BE%E8%88%8D/2026_0928_%E7%B2%BE%E9%80%B2%E8%8A%B1%E5%9C%92/garden_app/garden3d.html) 3D 智慧蓮池視角，可自由體驗。

2. **學員身分建檔與彈性打卡**：
   - **學號**：一開始頁面即可輸入學號（**非必填**）。
   - **班級**：支援 **日高**、**夜高**（必選）。
   - **組別**：第 1 組 ～ 第 12 組（必選）。
   - **姓名**：真實姓名（存檔建檔用）。
   - **法名**：學員法名（他人花園公開顯示用）。

3. **支援歷史補填時間（可補打卡）**：
   - 預設記錄「當前修持時間」。
   - 提供「**補填歷史修持時間**」勾選切換，可自選過去的日子與時間補交定課。
   - 支援禪坐時長、經典品名/卷數、持咒名稱/遍數、中台四箴行省思與修持心得。

4. **參觀他人花園（蓮池海會）＆ 嚴格安全隱私保護**：
   - 學員可自由瀏覽同修的精進花園，進入對方的開心花園漫步、澆水與合掌隨喜（🙏）。
   - **隱私安全性**：進入他人花園時，系統**「只能看到班級與法名」**，學號與真實姓名被**嚴格過濾遮蔽**，杜絕隱私洩漏。

5. **每日老和尚法語（出處：《中台月刊》）**：
   - 頂部收錄惟覺安公老和尚於歷期《中台月刊》的珍貴開示金句（含主題分類與出處期數）。
   - 開心花園頂部附有「📢 金喇叭每日開示廣播跑馬燈」，每日自動啟迪學員心靈。

6. **最高權限師父管理後台 (`admin.html`)**：
   - 採用高強度管理密碼防護：預設金鑰 `ZhongTai#ZenGarden2026!`。
   - 供指導法師與執事幹部查閱全班未脫敏名錄（真實姓名、學號、打卡次數、禪坐總時長）。
   - **法師線上即時批註開示**：指導法師可直接在學員心得下方批註提點，學員於「我的修持歷程」中可同步看見法師慈悲法語。
   - 支援修持資料一鍵備份匯出（JSON 格式）。

## 🚀 本地立即測試驗證

本專案內建 **無縫雙軌離線引擎 (`js/api.js`)**。在尚未配置 Cloudflare D1 前，可以直接在本機進行 100% 完整測試：

1. **直接開啟測試**：
   - 使用瀏覽器直接雙擊開啟 `index.html`。
   - 或使用 VSCode 的 Live Server / 簡易 HTTP Server 預覽。
2. **測試功能路徑**：
   - **測試打卡**：
     - 班級選【日高】、組別選【第 1 組】、學號可不填或輸入 `NT2026-001`、輸入姓名與法名。
     - 勾選【補填歷史修持時間】，選擇前天的時間，填寫靜坐 30 分鐘，點擊「恭敬送出」。
   - **測試 3D 花園**：
     - 送出後點擊「前往 3D 智慧蓮池」或導覽列「🌸 進入 3D 花園」。
     - 觀察蓮花程序化生長、水面波光、右側點擊切換【晨曦/正午/晚霞/禪月】，點擊【🔔 頌缽清音】聆聽合成鐘聲。
   - **測試參觀他人花園（蓮池海會）**：
     - 回到首頁點擊「🪷 參觀同修花園」。
     - 檢視同修清單：確認畫面中**只能看到【班級】與【法名】**（如：【日高】傳覺、【夜高】傳心），**真實姓名與學號完全隱藏**！
     - 點擊「進入 3D 花園參觀」，進入他人專屬 3D 蓮池，點擊「🙏 隨喜功德」。
   - **測試最高權限管理員**：
     - 點擊右上角「🔒 師父管理」或開啟 `admin.html`。
     - 輸入密碼：`ZhongTai#ZenGarden2026!`。
     - 解鎖後檢視完整名錄（含真實姓名與學號）、在心得下方填寫法師批註開示並儲存。

## ☁️ 方案 1：Cloudflare Pages ＋ D1 雲端架設 SOP

當準備將專案發布至雲端時，依循以下官方步驟：

### 步驟 1：建立 Cloudflare D1 資料庫
在終端機中透過 Wrangler 建立資料庫：
```bash
npx wrangler d1 create zen_garden_db
```
終端將回傳 `database_name` 與 `database_id`。請將該 `database_id` 填回專案的 `wrangler.toml` 中：
```toml
[[d1_databases]]
binding = "DB"
database_name = "zen_garden_db"
database_id = "貼上您的_D1_DATABASE_ID"
```

### 步驟 2：執行 SQL 遷移建表
執行專案內建的 `schema.sql`，建立 `students`, `checkins`, `rejoices`, `admin_config` 資料表：
```bash
# 本地模擬測試執行
npx wrangler d1 execute zen_garden_db --local --file=./schema.sql

# 正式雲端 D1 執行
npx wrangler d1 execute zen_garden_db --remote --file=./schema.sql
```

### 步驟 3：部署至 Cloudflare Pages
在專案根目錄執行發布命令：
```bash
npx wrangler pages deploy . --project-name=zen-garden-2026
```
部署完成後，在 Cloudflare Dashboard：
1. 進入 **Workers & Pages** > 點選 **zen-garden-2026** > **Settings** > **Functions**。
2. 在 **D1 database bindings** 區塊，新增綁定：
   - Variable name：`DB`
   - D1 database：選擇 `zen_garden_db`
3. 在 **Environment Variables** 區塊，可將最高權限密碼設為 Secret：
   - Variable name：`ADMIN_PASSWORD`
   - Value：`您自訂的高強度密碼`
