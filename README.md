# 精進花園 (Zen Practice Garden 2026)
### 中台禪寺精舍 ｜ 日高 ＆ 夜高 專修 2D 虛擬修持花園暨雲端打卡系統

> **「人在哪裡，心就在哪裡。一念清淨，即是自性花開。」** —— 惟覺安公老和尚《中台月刊》法語開示

本專案專為精舍**日間高級禪修班（日高）**與**夜間高級禪修班（夜高）**學員量身打造。將學員每日的靜坐與誦經定課，化為甘露法水注入蓮池，在 2D 精進花園中動態培育盛開生機盎然的**蓮花**與向陽**太陽花**。

---

## 🌟 核心規範與設計特色

1. **登入 / 註冊入口門檻 (Gatekeeper)**：
   - 進入網站首先呈現「修持登入」卡片，未登入前不會顯示花園與打卡面板。
   - 註冊/登入欄位：
     - **學號**：選填（非必填）。
     - **班級**：日高、夜高（必選）。
     - **組別**：A1、A2、B1、B2、B3、B4（必選）。
     - **真實姓名**：必填（僅供師父後台查閱，他人花園中**嚴格隱藏**）。
     - **法名**：必填（他人花園中**公開顯示**）。

2. **打卡次數注入蓮池 · 動態盛開蓮花＋太陽花**：
   - **純淨花園底圖**：背景圖片本身**無預繪花朵**，代表自性清淨心田。
   - **打卡動態生長**：
     - **蓮池蓮花**：打卡次數越多，池中從初發清荷、含苞、盛開粉紅芙蕖，乃至 10 次以上綻放「七寶金光大祥蓮」光暈。
     - **向陽太陽花**：打卡累積注入善法，肥沃土地上向陽生長並盛開太陽花（向日葵）。
   - 打卡時伴隨**甘露水注入動畫**與**空靈水聲/音缽音效**。

3. **保留木牌老和尚法語**：
   - 花園中木牌對齊《中台月刊》開示法語。
   - 點擊木牌即可彈出專屬對話窗，恭讀老和尚開示，並支援一鍵隨機抽取換則。

4. **精簡修持打卡內容**：
   - 僅保留**【靜坐】**（分鐘數）與**【每日誦經】**。
   - 經典選項：**金剛經**、**藥師經**、**普門品**，或可**自訂經典**填寫名稱。
   - **移除卷數**，**移除持咒品名與遍數**。
   - **支援歷史補打卡**：勾選「補打卡之前時間」，可自選過往日期時間進行補登。

5. **移除右下角工具列與「我的修持歷程」**：
   - 專注於花園與每日用功，版面純淨沉穩，無多餘工具按鈕干擾。

6. **參觀他人花園（蓮池海會）＆ 嚴格安全隱私保護**：
   - 學員可點擊「🌸 參觀同修花園」，在右側抽屜中瀏覽日高、夜高同修名錄。
   - **隱私安全性**：進入他人花園時**「只能看到班級與法名」**，學號與真實姓名被**嚴格過濾遮蔽**，杜絕個人隱私洩漏。
   - 進入同修花園可欣賞其打卡累積盛開的蓮花與太陽花，並可點擊「🙏 隨喜讚嘆合掌」。

7. **最高權限師父管理後台 (`admin.html`)**：
   - 採用高強度管理密碼防護：預設金鑰 `ZhongTai#ZenGarden2026!`。
   - 指導法師可查閱全班未脫敏名錄（真實姓名、學號、組別、打卡次數、禪坐總分鐘數）。
   - 法師可直接在學員打卡紀錄下方批註提點開示。
   - 支援修持資料一鍵備份匯出（JSON 格式）。

## 🚀 本地立即測試驗證

本專案內建 **無縫雙軌離線引擎 (`js/api.js`)**。在尚未配置 Cloudflare D1 前，可以直接在本機進行 100% 完整測試：

1. **直接開啟測試**：
   - 使用瀏覽器直接雙擊開啟 `index.html`。
2. **測試步驟**：
   - **登入門檻驗證**：
     - 一開始僅看到「精進花園 · 活動登入」卡片（普慶精舍 ｜ 禪修班）。
     - 班級選【日高】、組別選【A1】、真實姓名填【陳大明】、法名填【傳心】。
     - 點擊「🌸 進入精進花園」。
   - **花園與打卡體驗**：
     - 進入後，花園呈現純淨水池與土地，木牌顯示老和尚法語。
     - 點擊木牌，彈窗閱讀開示，點擊「換一則開示」。
     - 在右側打卡面板：填寫靜坐 30 分鐘，經名選「金剛經」。
     - 點擊「🪷 功德注入蓮池 · 完成今日修持」。
     - 觀察池中甘露水注入動畫、水滴音效，池中初露清荷，土地冒出向陽太陽花！
   - **參觀同修花園**：
     - 點擊右上「🌸 參觀同修花園」，側邊欄展開名錄。
     - 點擊同修「進入逛逛」，頂部出現參觀提示列，學號與真實姓名已被嚴格隱藏，僅顯示班級與法名。
     - 點擊「🙏 隨喜讚嘆合掌」，隨喜數增加並散落花雨。
     - 點擊「🌿 返回我的花園」。
   - **師父後台管理**：
     - 點擊「🔒 師父管理」或開啟 `admin.html`。
     - 輸入密碼：`ZhongTai#ZenGarden2026!`。
     - 查閱真實姓名、學號、打卡次數與靜坐時長。

## ☁️ 方案 1：Cloudflare Pages ＋ D1 正式架設指南

### 步驟 1：安裝與登入 Wrangler CLI
```bash
npm install -g wrangler
wrangler login
```

### 步驟 2：建立 Cloudflare D1 資料庫
```bash
# 建立名為 zen_garden_db 的 D1 資料庫
wrangler d1 create zen_garden_db
```
執行後終端機會印出 `database_name` 與 `database_id`。請將該 `database_id` 填入本專案的 [`wrangler.toml`](file:///E:/%E7%B2%BE%E8%88%8D/2026_0928_%E7%B2%BE%E9%80%B2%E8%8A%B1%E5%9C%92/garden_app/wrangler.toml)：
```toml
[[d1_databases]]
binding = "DB"
database_name = "zen_garden_db"
database_id = "你的_D1_DATABASE_ID"
```

### 步驟 3：執行 SQL 結構遷移
```bash
# 初始化資料表 (學員表、打卡表、隨喜表、管理員設定)
wrangler d1 execute zen_garden_db --file=./schema.sql
```

### 步驟 4：部屬至 Cloudflare Pages
```bash
wrangler pages deploy . --project-name zen-garden-app
```
部屬成功後，Cloudflare 會提供一個免費的正式網址（如 `https://zen-garden-app.pages.dev`），即可提供日高與夜高全體同修日常使用！
